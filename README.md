# work_agentlink6
Build two files that work together: 1. pipeline.py — fetches posts from https://jsonplaceholder.typicode.com/posts,     filters to first 10, serves them as JSON via HTTP on port 8080. 2. index.html — calls localhost:8080, displays the posts in a clean card list,     shows record count and fetch time. Open directly in browser, no dependencies.
